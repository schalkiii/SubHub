订阅管理

批量添加订阅

每行一个订阅链接，支持 clash / sing-box / v2ray / base64 格式。添加后会自动测速并进行健康度检测。

粘贴节点内容

直接粘贴节点 URI 或 clash / sing-box 文本（属于本地订阅，不会再次抓取）。可填写下方名称，便于在节点列表的「归属订阅」列区分来源；留空则自动命名为「本地导入 N」。

备份 / 恢复订阅列表

导出当前全部订阅（含每个订阅的节点与已测速结果）为 JSON 文件，可在本机或其他机器离线恢复或留档。导入按「来源链接」合并：已存在的远程订阅更新其节点，新的订阅追加；已测速数据一并保留，不会重新测速。

设置

所有全局偏好集中在此（代理、刷新、测速引擎、自动移除、Top-N）。修改即时保存并持久化，无需重启。

拉取代理

使用代理拉取 / 刷新订阅 关闭后，已添加订阅的刷新也会直接连接（不使用代理）。

代理地址由服务端统一记住（添加订阅时自动保存为默认，下次自动填充）。拉取被墙的订阅时填此项（例如本机 Sparkle / Clash 的 7890 端口），添加与后续刷新都会走该代理。

定时自动刷新

分钟 0 = 关闭；仅作用于远程订阅；增量更新（保留存活节点数据、仅测新节点、移除已删节点）
分钟 0 = 关闭；独立开关。定时重新探测每个节点的连通性/延迟（TCP 测通，受并发队列限制，不会瞬间高并发），自动移除连续不可用节点仍生效

测速引擎

指向 mihomo / sing-box 可执行文件（如 verge-mihomo.exe），用于真实代理延迟与下载带宽；保存后下次测速即生效，并持久化。

自动移除

次 连续测速不可用达到该次数后自动删除节点（0 = 关闭，不自动删除；建议 5）

全局 Top-N（导出 / 网页订阅统一控制）

只保留评分最高的 个节点 按延迟 / 带宽 / 解锁综合打分，取前 N 个。在此统一设置后，「合并并导出」与「本地订阅地址（/sub）」都遵循此值（关闭 = 全部节点）。订阅 URL 上带 top_n 可临时覆盖。
