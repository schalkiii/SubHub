二、修复详解

P1 · fingerprint 碰撞丢节点（高）→ core/src/model.rs

原 fingerprint() 只用 name+server+port，不含凭证。多节点供应商常复用同一 host，同名不同 uuid/password 的节点被当成重复而丢弃。修复：按类型补入凭证字段（vmess/vless/tuic 用 uuid；ss 用 method+password；trojan/hysteria2/socks5/http 用 password）。相同节点仍正常去重，真实不同节点不再被误删。

let cred = match self.type_ {
    Vmess|Vless|Tuic => self.uuid.clone().unwrap_or_default(),
    Ss => format!("{}|{}", method?, password?),
    Trojan|Hysteria2|Socks5|Http => self.password.clone().unwrap_or_default(),
    _ => String::new(),
};
format!("{}|{}|{}|{}|{}", type, server, port, name, cred)

P2 · load_all 静默丢订阅（高）→ server/src/db.rs

原循环 if let Ok(sub) = from_str { out.push } 在单条订阅解析失败时整条丢弃且无声。修复：解析失败时打印告警，并尝试节点级容错——把仍能解析的 proxy 保留、跳过坏节点后重建订阅，最大化恢复历史数据。

match serde_json::from_str::<Subscription>(&r) {
    Ok(sub) => out.push(sub),
    Err(e) => { eprintln!("[db] 订阅解析失败，尝试节点级容错: {e}");
                /* 解析 proxies 数组，逐项 from_value，跳过坏节点后重建 */ }
}

P3 · sing-box 导出 direct（中）→ core/src/export.rs

singbox_outbound 改为返回 Option<Value>，为 hysteria2/tuic/socks5/http 生成真正的 outbound（hysteria2/tuic 带 tls，socks 标 version 5）；wireguard 与未知类型打印告警并跳过（不再产出 direct 伪节点）。to_singbox_json 用 filter_map 收集。

ProxyType::Hysteria2 => { o["type"]="hysteria2"; o["password"]=...; tls?; Some(o) }
ProxyType::Tuic       => { o["type"]="tuic"; o["uuid"]=...; o["password"]=...; Some(o) }
ProxyType::Socks5     => { o["type"]="socks"; o["version"]="5"; pw?; Some(o) }
ProxyType::Http       => { o["type"]="http"; pw?; Some(o) }
ProxyType::Wireguard => { eprintln!("...不支持 wireguard，已跳过"); None }

P4 + P7 · 评分（中/低）→ server/src/lib.rs score_proxy

原：if !available.unwrap_or(false) { return 0.0 } 对未测（None）与失败（Some(false)）一视同仁记 0。注意 import_raw 导入即自动跑 TCP 测速，不可达节点被标 Some(false) → 全部 score 0 → Top-N 把它们全剔除。修复：仅 Some(false) 记 0；未测节点用中性延迟 500ms 参与排序，避免被静默丢弃。同时带宽仅在 bandwidth_measured && is_finite() 时计入，杜绝 NaN 污染。

let latency_ms = match p.available {
    Some(false) => return 0.0,
    Some(true)  => p.latency_ms.unwrap_or(2000),
    None        => 500, // 未测节点中性假设，Top-N 不静默剔除
};
let bw = if p.bandwidth_measured && p.download_speed_bps.is_some_and(|b| b.is_finite()) {
    p.download_speed_bps.unwrap_or(0.0)
} else { 0.0 };

P5 · webui XSS（中）→ webui/app.js

节点表 outbound_country 与 region 原样拼入 innerHTML（outbound_country 由外部引擎写入，不可信）。改为 escapeHtml(...)。

P6 · 地域陈旧（低）→ server/src/lib.rs geo_detect

原 if let Some(Some(cc)) = ... 只在探测返回 Some 时更新；返回 None（失败/无引擎）时保留旧值。改为 if let Some(cc) = ... 总是刷新（None 即清掉旧地域）。

P8 · 分享 URL 端口（低）→ webui/app.js

buildShareUrl 由写死 http://127.0.0.1:3005/sub 改为 window.location.origin + "/sub?..."，跟随实际服务端口（含 N5 的 SUBHUB_PORT）。
